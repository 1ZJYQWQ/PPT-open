# PPT 演示侧边栏

放映幻灯片时浮在屏幕边上的一个工具条：上一页 / 下一页 / 笔 / 橡皮 / 结束放映。

不抢键盘焦点，所以翻页笔、方向键照常用。开始放映它自动贴边冒出来，放完自己缩回托盘。

## 跑起来

```bash
dotnet build -c Release
双击 启动侧栏.cmd
```

需要 Windows 10/11、.NET 10 SDK、以及装好的 PowerPoint 桌面版。

## 怎么用

- 在 PowerPoint 里按 F5 放映，侧栏自动弹出贴边
- 笔的颜色点按钮右侧的色条就能换，会自动记住
- 橡皮双击 = 清空本页笔迹
- 标题栏拖动可移动，拖到屏幕左/右半边松开就吸附贴边
- 不想要了点右上角 ✕ 收进托盘，或托盘图标右键退出

按钮只在放映时生效；普通编辑视图里点会提示"当前没有幻灯片放映窗口"。

无VSTO需求，需要 .NET10运行时支持
